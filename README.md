# Proximity Voice

Voice chat for [Horizon](https://playhorizon.dev) on servers that run
[Plasmo Voice](https://github.com/plasmoapp/plasmo-voice) 2.x. The server sees an ordinary Plasmo Voice
client: you hear the players near you, quieter the farther they are, and they hear you, whether they play
Horizon or Java Edition with the Plasmo Voice mod. Add-ons that use Plasmo Voice (groups, music discs such as
CDisc Music) work too.

This is a port of Plasmo Voice's client to Horizon, following its protocol, not an official Plasmo Voice
release. Plasmo Voice is made by [plasmoapp](https://github.com/plasmoapp); the design, the protocol and the
icons are theirs.

## What it does

- Joins the server's voice chat by itself: it registers `plasmo:voice/v2`, answers the server's handshake
  (RSA key exchange, AES/CBC voice encryption) and keeps the UDP link to the voice server.
- Sends your microphone, encoded with Opus at the server's rate and bitrate, on every activation the server
  offers (proximity, and add-ons' such as groups), heaviest first as Plasmo Voice orders them: push to talk,
  voice activation or "as proximity", a key that is held or toggles, and each activation's distance.
- Plays every source from where it is: players, entities (a plugin's jukebox), fixed places. The volume
  follows the distance as Plasmo Voice's does (linear, or cubed by default), in both ears, or panned left and
  right when you turn that on. Blocks between can muffle voices. Gains glide, so turning doesn't crackle.
- A settings screen in Plasmo Voice's layout (V): devices, volumes of each source line and each player (with
  mute and search), activations, overlay, microphone filters (noise gate, compressor, limiter), and keys.
- The microphone's state over the hotbar, who is speaking in a corner, and marks over speaking or muted
  players' names. Add-ons' own icons, which servers send as pictures, are shown as theirs.
- English and Russian, after the game's language.

## Keys and commands

| | Default |
|---|---|
| Voice settings | V |
| Push to talk (proximity) | Left Alt |
| Mute microphone | M |
| Voice chat on/off, distance up/down, blocks muffle on/off, talk on other activations | not bound |

Rebind them on the settings screen's Keys tab (or in Options > Mods > Proximity Voice).

`/vc` says how the voice is doing; `/vc menu`, `/vc mute|unmute|deafen|undeafen`, `/vc mute <player>`,
`/vc debug` (where each source heard was placed).

## What it accesses

- **Microphone**: opened only on a server whose Plasmo Voice configures voice chat, closed when you leave it
  (or never, with "Disable input device").
- **Network**: UDP to the voice server the game server names (its own address, or the one in its config), and
  plugin messages on `plasmo:voice/v2` on the game connection. Audio is sent only while an activation speaks.
  Nothing else is contacted.
- **Files**: its settings in the game folder (`horizon-mods/.horizon-mod-data/proximity_voice/`) and its keys
  in the game's options.

## Limits

- Made and tested on Windows. The audio goes through cpal, as Horizon's own sound does, so Linux and macOS
  should work, untested.
- Horizon gives mods no textures: icons are drawn pixel by pixel. No skin heads in the overlay, no HRTF, no
  stereo capture; a noise gate stands in for RNNoise.
- Horizon joins offline-mode servers only (Microsoft sign-in isn't there yet), so this works on those.
- The mod hooks Horizon's own functions (the packet handler, dialogs for its screen, name tags), so it pins
  its Horizon Nightly and is updated for new ones.

## How it is built

A native mod (`mixins/proximity_voice/`) for horizon-mixins 0.6 (it uses a bundle crate):

- `runtime.rs` becomes `crate::game::proximity_voice`: the channel, keys, `/vc`, settings, the HUD and the
  settings screen. `marks.rs` becomes `proximity_marks` in horizon-client-render, for the name tags.
- The helpers hook `Game::handle_packet` (the server's payloads, the login, tracked entities),
  `Game::send_chat`, the dialog screen's functions (the settings screen takes its place), `HudBatch::name_tag`,
  and Horizon's hook points (tick, HUD, keys, commands, Options > Mods).
- `engine/` is a crate of its own (`[[crate]]`, with cpal, getrandom and png from Horizon's Cargo.lock): the
  protocol (`proto.rs`), AES (`aes.rs`), the UDP link, encoders and decoders (`engine.rs`, `codec.rs`), the
  filters (`dsp.rs`), the mixer and devices (`mixer.rs`, `audio.rs`), icons (`icons.rs`, generated by
  `tools/icons.py` from Plasmo Voice's; `texture.rs` for sent ones). `engine/src/opus/` is
  [rusty-opus](https://crates.io/crates/rusty-opus) 1.0.2, a pure-Rust Opus codec, vendored with only its
  paths changed. RSA is Horizon's own (`horizon_protocol::rsa`).

Tests: `cargo test` in a crate that depends on `mixins/proximity_voice/engine` (91 tests, rusty-opus' among
them). Check against Horizon: `horizon-mixins apply --workspace <horizon at the pinned commit> --mods mixins
--out <stage>`, then `cargo check --locked -p horizon-client --bin horizon-client` in the stage. Package:
`python tools/package.py` writes `dist/proximity_voice-<version>.hnmod` (as horizon-mods' `native.py package`,
but with the bundle's files at every depth: the engine crate is a folder).

## По-русски

Голосовой чат для Horizon на серверах с Plasmo Voice 2.x. Сервер видит обычный клиент Plasmo Voice: вы
слышите игроков рядом (и в Horizon, и в Java с модом Plasmo Voice), тише, чем дальше они, а они слышат вас.
Работают аддоны: группы, пластинки (CDisc Music). Меню: V, говорить: Left Alt, микрофон: M, `/vc` показывает
состояние.

Это порт клиента Plasmo Voice по его протоколу, не официальный релиз; авторы Plasmo Voice — plasmoapp.
Лицензия LGPL-3.0, как у оригинала.
